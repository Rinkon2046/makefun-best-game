Neon Salvage is an original neon arcade game for the desktop browser: pilot a salvage drone, haul energy cores to build combos, grab shield orbs, dodge drift mines and hunter wisps, and reach 4000 points to complete the contract before your three hull points run out.

## Run it

```sh
python3 -m http.server 8080 --directory game   # then open http://localhost:8080
```
